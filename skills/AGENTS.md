## Adding a skill here

The detection contract is unforgiving and fails **silently**. Three names must agree or
the skill degrades to markdown behind a load warning nobody reads:

1. the directory name — `sol-orchestration`
2. the `name:` in its `SKILL.md` frontmatter
3. the Python import identifier — `sol_orchestration`, hyphens to underscores

Plus a project file at the skill root and a `src/` layout whose directory matches the
import identifier. `scripts/verify-prime-agent-package.sh` checks all of it; run it
after any rename.

Declaring a new skill also widens the root footprint, which is three paths by explicit
decision. Decide to, rather than drift into it.
